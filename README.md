# Ahmed Shokr — متجر الباقات

## الملفات
- `index.html` واجهة المتجر.
- `style.css` التصميم المتجاوب.
- `script.js` أسعار الباقات وسلوك نموذج الطلب.

## تعديل الأسعار ورقم واتساب
افتح `script.js` وعدّل `price` لكل باقة. لإضافة واتساب، ضع رقمك بصيغة دولية بدون علامة `+` داخل:
`const WHATSAPP_NUMBER = "2010XXXXXXXX";`

## معاينة ونشر مجانية على GitHub Pages
1. أنشئ مستودع GitHub جديدًا.
2. ارفع الملفات الثلاثة إلى المجلد الرئيسي للمستودع.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)` واحفظ.
5. انتظر اكتمال النشر وافتح رابط Pages الذي يعرضه GitHub.

## ملاحظات مهمة
هذه نسخة واجهة أمامية فقط. لا تنفذ دفعًا إلكترونيًا أو تفعيل باقات تلقائيًا ولا تحفظ الطلبات على خادم. لطلبات فعلية تحتاج إلى backend آمن وربط مع مزود دفع/تفعيل معتمد. لا تجمع كلمات مرور فودافون أو فودافون كاش.
