# Ahmed Shokr Orders — Prototype v1

واجهة طلب باقات عربية RTL، مناسبة للنشر كمعاينة على GitHub Pages.

## الملفات
- `index.html`: واجهة العميل
- `style.css`: التصميم
- `app.js`: اختيار الباقة وتسجيل معاينة محلية للطلب

## مهم قبل استقبال عملاء حقيقيين
هذه نسخة واجهة أولية فقط. الطلبات تحفظ في متصفح نفس الجهاز باستخدام localStorage، ولا تصل إلى لوحة تحكم مركزية، ولا يتم التحقق من الدفع تلقائيًا. لا تستخدمها لاستقبال طلبات فعلية قبل ربطها بقاعدة بيانات وخدمة خلفية وتسجيل دخول إداري آمن.
لا تطلب كلمة مرور تطبيق أنا فودافون أو OTP. استخدم فقط آلية تفويض رسمية وآمنة إن كانت متاحة.

## نشر المعاينة على GitHub Pages
ارفع `index.html`, `style.css`, `app.js` إلى جذر المستودع ثم من Settings → Pages اختر Deploy from a branch، والفرع `main` والمجلد `/(root)`.
