Ahmed Shokr - HTML learning store

Files:
- index.html: complete single-file demo (HTML + CSS + JavaScript).

How to test:
1. Open index.html in a browser.
2. Choose a package, fill the form, and press "جهّز رسالة الطلب".
3. Press "إرسال الطلب على واتساب" to open WhatsApp with a prepared message.

Before publishing:
- Verify package prices and payment details.
- This is a static frontend. It does not store orders in a server/database.
- Payment confirmation is manual. Never ask customers for account passwords or OTP codes.
- Upload index.html to the root of your GitHub repository and enable GitHub Pages.
